# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [v0.1.0] - Unreleased
### Added
- Initial MVP release.
- Core terminal emulator powered by xterm.js and a custom Go pty backend.
- Multi-tab terminal support.
- Real-time system monitoring visualizations (CPU, RAM, Net).
- File browser sidebar.
- Authentic retro-futuristic boot animation sequence.
- Complete theme system with support for custom JSON themes.
